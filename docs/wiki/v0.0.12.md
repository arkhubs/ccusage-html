# ccusage-html Wiki v0.0.12

## Version Goal

v0.0.12 expands session transcript support beyond Codex and makes the Sessions drawer more robust for rendered Gemini conversations:

- Gemini sessions now resolve local transcripts from `~/.gemini/tmp/**/chats/session-*.json*`.
- Gemini session dates, titles, snippets, and full conversation turns are recovered when `ccusage session --json` exposes matching session IDs.
- Codex and Gemini tool calls are shown as compact `Tool` turns in the conversation drawer.
- Rendered Markdown bubbles no longer overflow the drawer width on long Gemini messages.
- Transcript parsing is moved behind a shared provider registry so future agent formats can be added without growing `sessions.py`.

## Why This Changed

`ccusage` session records for Gemini only expose aggregate usage fields and a UUID-like period/session ID. They do not include a timestamp, title, transcript path, or conversation body. As a result, Gemini sessions previously appeared as `Unknown` date rows with no readable conversation.

The local Gemini CLI data does contain the missing context, but it lives in a different format from Codex:

- older Gemini files are whole-session `.json` documents with a `messages` array;
- newer Gemini files are append-style `.jsonl` files with metadata and incremental message updates;
- assistant text may be stored in `content`, `thoughts`, or tool-call metadata;
- the same message ID may appear multiple times as extra fields are appended.

At the same time, rendered Markdown exposed a layout bug: long Gemini text and inline code could force chat bubbles past the drawer boundary because flex children were using content-derived minimum widths.

## User-Facing Behavior

Generated reports now enrich Gemini sessions by default when matching local files are available. In the Sessions tab, Gemini rows can show:

- real session dates instead of `Unknown`;
- titles derived from the first non-context user message;
- snippet previews in cards;
- full conversation turns in the detail drawer;
- compact tool-call context such as tool name, description, arguments, command, working directory, and status.

`--no-transcript` still disables all local transcript enrichment. A new `--gemini-sessions-dir` option can override the default Gemini root when the local session directory is not `~/.gemini/tmp`.

In rendered mode, long paragraphs, inline code, and tool-call text wrap inside the drawer. The drawer now hides horizontal overflow at the scroll container while preserving normal vertical scrolling and pre/code block scrolling.

## Transcript Provider Framework

Transcript enrichment now has a small shared framework in `scripts/ccusage_html_report/transcripts.py`:

- `TranscriptProvider` defines the agent-specific parser contract.
- `TranscriptEnrichmentRegistry` maps normalized agent names to providers.
- `build_transcript_registry()` builds providers once per report generation.
- `CodexTranscriptProvider` owns Codex JSONL lookup and turn extraction.
- `GeminiTranscriptProvider` owns Gemini session indexing, JSON/JSONL parsing, message merge logic, and tool-call extraction.

`scripts/ccusage_html_report/sessions.py` now focuses on normalizing ccusage session rows, usage fields, model names, dates, titles, and fallback empty transcript fields. It delegates local transcript details to the registry.

This keeps the path open for future support of Claude Code, Qwen, opencode, or other agent software: add a provider, register it, and keep the output shape as `snippets`, `conversation`, and `transcriptPath`.

## Implementation Notes

- `cli.py` adds `--gemini-sessions-dir`.
- `report.py` builds a transcript registry instead of passing Codex/Gemini details directly into session normalization.
- `sessions.py` is reduced to ccusage session normalization and sorting.
- `transcripts.py` centralizes shared transcript helpers, context-noise filtering, turn creation, datetime backfill, Codex parsing, and Gemini parsing.
- `report-sessions.js` recognizes a third conversation role, `tool`, and renders it separately from user and assistant turns.
- `report.css` adds tool-turn styling and fixes rendered bubble overflow with `min-width: 0`, bounded bubble widths, stronger inline-code wrapping, and hidden horizontal overflow in the drawer scroll container.
- `README.md`, `SKILL.md`, and the project development checklist now describe Gemini transcript support and the provider registry.

Gemini context bootstrap messages such as `<session_context>` are filtered out so titles and snippets start from actual user-visible conversation content.
