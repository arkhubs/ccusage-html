# ccusage-html Wiki v0.0.2

## 版本目标

v0.0.2 聚焦三个问题：

- `all` 聚合模式下可以按模型查看 token 和 cost。
- Cost 作为一类总量指标进入汇总、图表和 session 明细。
- Session 支持展开详情，展示 token 类型、模型拆分、成本、上下文 token 估算和可用的 Codex 本地完整对话。

## 快速开始

```powershell
uv run python .\scripts\generate_ccusage_report.py all --serve --port 8765
```

生成静态 HTML：

```powershell
uv run python .\scripts\generate_ccusage_report.py all --output .\ccusage-report.html
```

只看 Codex 并嵌入本地对话：

```powershell
uv run python .\scripts\generate_ccusage_report.py codex --since 2026-06-01 --output .\ccusage-codex.html
```

不嵌入 transcript：

```powershell
uv run python .\scripts\generate_ccusage_report.py all --no-transcript --output .\ccusage-public-ish.html
```

## UI 变化

### Usage 首页

Usage 现在是主视图，顶部直接展示 Model mix，不再单独提供 Models 顶层 tab。

Model mix 卡片展示：

- Total tokens
- Input tokens
- Output tokens
- Reasoning tokens
- Context tokens
- Cost

下面仍保留 daily、weekly、monthly 图表，并支持图例按模型开关。点击柱状图会按时间桶和模型过滤 Sessions。

### Cost 指标

Metric 切换新增 `Cost`：

- Total tokens
- Input
- Output
- Reasoning
- Cost
- Cache read
- Cache creation

Cost 只按 total cost 展示，不拆 input/output cost。

### Sessions

Sessions 仍支持：

- 搜索
- Recent / Tokens / Cost / Title 排序
- Cards / List 视图切换
- 图表联动过滤

每个 session 新增 `Show details` 展开按钮。展开后展示：

- token 类型明细：Total、Input、Output、Reasoning、Cache create、Cache read、Context、Generation、Cost
- per-model 表格：Model、Total、Input、Output、Reasoning、Cache、Context、Cost
- Conversation：能定位到 Codex JSONL 时，展示本地完整 user/assistant 对话 turn
- Transcript 本地路径

## 数据口径

### `all` 模式模型拆分

`ccusage daily/monthly/weekly/session --json` 的聚合输出可能使用：

- `models`
- `modelBreakdowns`
- `modelsUsed`
- `costUSD`
- `totalCost`
- `cost`

v0.0.2 在 `report.py` 中统一归一化为前端使用的：

- `models`
- `modelNames`
- `costUSD`

因此 `all` 聚合 HTML 可以和 `codex` 单 agent HTML 一样按模型查看。

### Context tokens

当前 `contextTokens` 是估算字段：

```text
contextTokens = inputTokens + cacheCreationTokens + cacheReadTokens
```

`generationTokens` 是：

```text
generationTokens = outputTokens + reasoningOutputTokens
```

这两个字段用于 session 和模型明细展示，不改变 `ccusage` 原始 total token 口径。

### Transcript

Codex session 会尝试通过 session id 定位：

```text
~/.codex/sessions/YYYY/MM/DD/<session>.jsonl
```

提取规则：

- 只保留 `user` 和 `assistant` message。
- 跳过大型环境上下文、AGENTS instructions、system context。
- 卡片上仍只展示短 snippet。
- 展开详情中展示完整 conversation turn。

生成的 HTML 可能包含完整本地对话内容，应视为私有文件。
