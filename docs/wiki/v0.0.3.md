# ccusage-html Wiki v0.0.3

## 版本目标

v0.0.3 聚焦归档和入口暴露：

- 默认输出改为项目内 `reports/<timestamp>/ccusage-report.html`。
- 每次生成都会保留 raw ccusage JSON、归一化 report data、session records 和 manifest。
- 终端主动打印本地 URL、HTML 文件、归档目录、report data 和 raw data 路径。
- HTML 页脚也展示 URL、HTML 路径和归档目录，旧报告打开后仍能找到入口。

## 快速开始

```powershell
uv run python .\scripts\generate_ccusage_report.py all --serve --port 8765
```

命令会打印类似：

```text
Report URL: http://127.0.0.1:8765/ccusage-report.html
Report HTML: E:\Projects\Active\ccusage-html\reports\20260612-151530\ccusage-report.html
Archive directory: E:\Projects\Active\ccusage-html\reports\20260612-151530
Report data: E:\Projects\Active\ccusage-html\reports\20260612-151530\report-data.json
Raw data: E:\Projects\Active\ccusage-html\reports\20260612-151530\raw
```

不启动服务器也会归档：

```powershell
uv run python .\scripts\generate_ccusage_report.py codex --since 2026-06-01
```

自定义归档根目录：

```powershell
uv run python .\scripts\generate_ccusage_report.py all --reports-dir .\reports-archive
```

自定义 HTML 输出路径时，仍会创建 `reports/<timestamp>/` 归档，并在归档中保留一份 `ccusage-report.html` 副本：

```powershell
uv run python .\scripts\generate_ccusage_report.py codex --output .\ccusage-report.html
```

## 归档结构

```text
reports/
└─ 20260612-151530/
   ├─ ccusage-report.html
   ├─ manifest.json
   ├─ report-data.json
   ├─ sessions.json
   └─ raw/
      ├─ daily.json
      ├─ monthly.json
      ├─ session.json
      └─ weekly.json
```

| 文件 | 用途 |
| --- | --- |
| `ccusage-report.html` | 可直接打开的单文件仪表盘。 |
| `report-data.json` | 前端实际消费的归一化数据，包含 filters、models、periods、sessions、totals 和 archive metadata。 |
| `sessions.json` | session 记录单独导出，方便后续检索或二次分析。 |
| `manifest.json` | 本次报告入口信息：版本、生成时间、agent、过滤条件、HTML 路径、数据路径、URL。 |
| `raw/*.json` | `ccusage daily/monthly/session/weekly --json` 的原始输出。 |

## 隐私和 Git

`reports/` 已加入 `.gitignore`。这些文件会留在本地工作区，方便以后回看，但默认不会进入 Git 提交。

## 本轮主要变更

| 文件 | 变化 |
| --- | --- |
| `app.py` | 新增 reports 时间戳目录、归档写入、manifest、路径打印和 URL 打印。 |
| `report.py` | 将 raw payload 收集与 report data 归一化拆开，便于保存原始数据。 |
| `html.py` | 页脚展示 URL、HTML 路径和归档目录。 |
| `cli.py` | 新增 `--reports-dir`。 |
| `README.md` / `SKILL.md` | 更新默认归档行为和路径暴露说明。 |

## 验证记录

建议执行：

```powershell
uv run python -m compileall scripts
uv run python .\scripts\generate_ccusage_report.py all --no-transcript
uv run python .\scripts\generate_ccusage_report.py codex --since 2026-06-12 --serve --port 0
```

检查点：

- Python 编译通过。
- 默认输出位于 `reports/<timestamp>/ccusage-report.html`。
- `report-data.json`、`sessions.json`、`manifest.json` 和 `raw/*.json` 均存在。
- 终端输出包含 `Report URL`、`Report HTML`、`Archive directory`、`Report data`、`Raw data`。
- HTML 页脚包含 URL / HTML / Archive 信息。
