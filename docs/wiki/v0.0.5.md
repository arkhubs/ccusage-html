# ccusage-html Wiki v0.0.5

## 版本目标

v0.0.5 聚焦 Sessions 页面可读性和详情浏览体验：

- 强化 session 卡片和列表项之间的边界，避免多个 session 视觉上糊成一团。
- 取消卡片内联展开详情，改为右侧 sticky 详情栏，保持左侧列表稳定。
- 将详细 conversation 改成桌面 Agent app 风格的聊天气泡。
- 让 usage、models、conversation、transcript 在详情栏中分区展示，减少展开后的版面跳动。

## 背景问题

旧版 Sessions 页面把摘要、snippet、model 表格和完整 conversation 都塞在同一张 session 卡片里。展开一个 session 后会出现几个问题：

- session 之间边界不清，尤其在 card/grid 模式下容易混在一起。
- list 模式下展开内容会撑开整行，破坏列表扫描节奏。
- 详细信息和完整对话混在列表流中，用户很难一边比较 session，一边查看当前 session 详情。
- conversation 使用普通块状文本，和实际桌面聊天 Agent app 的阅读习惯不一致。

## v0.0.5 的处理方式

### 左侧：稳定的 session 浏览区

Sessions 主区域现在保留为浏览和筛选用途：

- 卡片模式使用更明确的边框、背景层次、hover 状态和 active 状态。
- 列表模式隐藏 snippets，只保留标题、元信息、核心指标和详情按钮，便于快速扫描。
- 点击卡片或 `View details` 会选中 session，而不是在卡片内部展开长内容。
- 搜索、排序、bar chart 过滤和 load more 继续复用原有数据逻辑。

### 右侧：session detail drawer

详情改为右侧栏：

- 右侧栏在桌面尺寸下 sticky，滚动列表时仍保留当前选中 session 的详情。
- 空状态提示用户选择一个 session。
- 选中 session 后展示标题、日期、agent、model 和关闭按钮。
- 详情内容分为 `Usage`、`Models`、`Conversation`、`Transcript`。
- 当筛选条件变化导致当前 session 不再匹配时，会自动清空选中状态。

### Conversation 聊天气泡

完整对话展示改为更接近桌面聊天 Agent app 的样式：

- user turn 和 assistant turn 分左右视觉方向。
- 每条消息带有简短头像、角色名、时间和字符数。
- 消息文本使用气泡容器展示，保留换行并支持长文本折行。
- assistant 和 user 使用不同的边框与背景色，方便快速区分。

### Models 明细

右侧栏宽度有限，旧版表格容易横向挤压。v0.0.5 将 model breakdown 改成自适应模型块：

- 每个 model 是一个独立块。
- token、cache、context、cost 等指标使用小型 metric grid。
- 避免在侧栏中出现横向滚动表格。

## 响应式行为

- 桌面宽度下使用 `sessions-shell` 双栏布局：左侧 session 列表，右侧详情栏。
- 窄屏下自动退回单列布局，详情栏位于列表下方。
- list 模式在窄屏下恢复纵向排列，避免指标和按钮挤压。
- 详情栏滚动区域限制高度，长 conversation 不会把页面整体撑散。

## 验证记录

Python 编译：

```powershell
uv run python -m py_compile scripts\ccusage_html_report\html.py
```

模板渲染断言：

```powershell
uv run python -c "import sys; sys.path.insert(0, 'scripts'); from ccusage_html_report.html import html_document; data={'generatedAt':'now','agent':'codex','agentInput':'codex','filters':{},'models':[],'modelPrices':{'models':{},'sources':[]},'metricLabels':{'totalTokens':'Total'},'periods':{'daily':[],'weekly':[],'monthly':[]},'sessions':[],'totals':{},'archive':{}}; html=html_document(data); assert 'sessionDrawer' in html; assert 'activeSessionKey' in html; assert 'model-breakdown' in html; assert 'expanded' not in html; print('render ok')"
```

浏览器预览验证：

- 打开本地最小样例 HTML。
- 切换到 Sessions tab。
- 点击第一条 session。
- 确认只有一张卡片处于 active 状态。
- 确认右侧详情栏显示 usage、models、conversation、transcript 分区。
- 确认 model breakdown 使用纵向模型块，不再使用侧栏表格。
- 确认 user / assistant conversation 以聊天气泡渲染。

## 注意事项

- 本轮只改前端 HTML 模板，不改变 ccusage 数据归一化逻辑。
- 旧报告 HTML 是静态文件，不会自动获得 v0.0.5 UI；需要重新生成 report。
- 详情栏会嵌入完整 Codex conversation，隐私注意事项与旧版一致：生成的 HTML 仍应作为本地私有数据处理。
