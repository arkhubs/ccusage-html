# ccusage-html Wiki v0.0.7

## Version Goal

v0.0.7 fixes a pricing regression introduced by the fast serve workflow:

- `--offline` now only affects the ccusage command, not report-side model price lookup.
- Added `--no-price-fetch` for users who explicitly want to skip external price metadata.
- Model breakdowns with nonzero usage and reported `cost=0` can be replaced by a current-price estimate when the estimate is nonzero.
- Price cards no longer show a strip full of `n/a` values when no rates were fetched.

## Why This Changed

Some ccusage outputs include model-level `cost: 0.0` for Gemini models when pricing is unavailable, while other models and total cost remain nonzero. The report previously treated that zero as authoritative and refused to estimate the model cost later.

The report now treats that shape as missing model-level cost when current price data can compute a nonzero estimate. The replaced value keeps `reportedCostUSD` and marks `costSource` as `estimatedFromModelPrice`.

## Recommended Command

```powershell
uv run python .\scripts\generate_ccusage_report.py all --serve --port 0
```

Optional faster local-only mode, accepting no report-side current prices:

```powershell
uv run python .\scripts\generate_ccusage_report.py all --serve --port 0 --no-price-fetch
```

## Notes

- The URL still appears immediately because the server starts before data and price collection.
- Price lookup remains best-effort and uses current rates, not guaranteed historical billing rates.
- Use `--offline` when you want ccusage itself to use cached pricing behavior; it no longer disables HTML report price estimates.
